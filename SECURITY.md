# Security

Report vulnerabilities privately with GitHub's private vulnerability reporting on this repository
("Security" tab → "Report a vulnerability"). Do not open public issues for exploits of the incentive
mechanism. Include the commit, a description and, if possible, a failing test. We aim to acknowledge
reports within 3 days.

Scope: miner and validator code, scoring, the wire protocol and the deployment files in this repository.
Known accepted risks are listed in [docs/THREAT-MODEL.md](docs/THREAT-MODEL.md).
